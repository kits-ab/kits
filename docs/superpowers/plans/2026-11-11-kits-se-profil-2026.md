# kits.se i profil 2026: grund och sidor — Implementation Plan

> **For agentic workers:** Genomförs inline (superpowers:executing-plans) med ett avsteg som Patrik
> beslutat: efter varje task stannar du och låter Patrik granska i dev-servern
> (`<dev-url>`) innan nästa task. Följ skillen `kits-profil-2026` i allt. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bygg om hela kits.se till KITS grafiska profil 2026 med `@kits-ab/kits-ui`, utan att
ändra struktur, URL:er, texter eller länkmål (utom Patriks beslut för startsidan).

**Architecture:** Först grunden (kits-ui via yalc, typsnitt, tema i `gatsby-ssr.tsx`, globala
stilar, router, sidhuvud, sidfot, byggstenar), därefter en sida i taget. Gamla
`@kokitotsos/react-components` lever kvar för ej ombyggda sidor tills sista sidan är klar.

**Tech Stack:** Gatsby 5, React 18.3.1, TypeScript, styled-components, `@kits-ab/kits-ui` 0.1.x
(yalc), react-aria (via kits-ui).

**Spec:** `docs/superpowers/specs/2026-11-11-kits-profil-2026-design.md`. Regler, namn och
verifiering: `.agents/skills/kits-profil-2026/` (lokalt i worktreet, ej committat).

## Global Constraints

- Worktreet för branchen `kits2026` (`git worktree list` visar var). Dev-serverns adress och logg
  står i `start`-skriptet i `package.json` (`<dev-url>` nedan).
- Följ skillen `kits-profil-2026`: bindande namn i `references/komponenter.md`, innehållsregler i
  `references/sidor.md`, tokens i `references/tokens.md`.
- Inga nya beroenden utöver `@kits-ab/kits-ui`. Gatsby 5 kräver React 18.
- Inga hex, `rgba()` med egna värden eller egna px-värden för typografi i sajtens kod.
- Texter, bilder och länkmål ändras inte, varken i `content/` eller i `src/pages/*.tsx`, utom de
  preliminära startsidebesluten i specen.
- Committa bara när Patrik säger till (efter hans granskning). Committa aldrig `.agents/`,
  `.claude/`, `AGENTS.md` eller `start`-skriptets ändring i `package.json` (port och tee).
  Inga AI-attributionsrader. Pusha aldrig.
- Testramverk saknas i sajten och får inte läggas till; varje task verifieras med `npm test`,
  `npm run build`, kontroller av byggd HTML och stegen i `references/verifiering.md`.

## Review Focus

- En sida som ännu inte är ombyggd ska se likadan ut som innan (gamla stilar kvar under
  övergången) men med nytt sidhuvud och ny sidfot; kontrollera minst `/kitsstudio` efter Task 4.
- Interna länkar ska navigera utan sidomladdning, `mailto:` och externa länkar ska fungera som
  vanligt (Task 3).
- Med JavaScript avstängt ska sidan vara mörk och läsbar (Task 2).
- Mobil 390 px: menyn går att öppna, stänga och använda med tangentbord (Task 4).
- Fokus syns på sidhuvudets Kontakt-knapp i mörkt läge (Task 0).
